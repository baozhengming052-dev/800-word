# v2.3.1 性能与交互真机验收清单

本清单针对 v2.3.0 连续学习卡顿。它是待执行步骤，不表示已经通过。两台先导出 v3 备份，再用 TrollStore **覆盖安装** v2.3.1；不要先卸载，保留现有个人词题和历史作为真实压力数据。

## 1. 连续词卡

- [ ] 打开“每日学词”，连续完成至少50个词，三种按钮交替使用。每次触摸立即出现缩放、描边/颜色变化和轻触反馈；松手后短暂显示“正在记录”，只前进一个词。
- [ ] 快速连点同一按钮或同时点两个按钮，不重复跳词、不重复增加错误次数。
- [ ] 第1、20、50个词的响应速度没有明显持续恶化；滚动释义、打开详情、返回词卡保持流畅，不再出现长时间画面不动但稍后集中响应。
- [ ] 开启“设置 → 辅助功能 → 动态效果 → 减弱动态效果”后不做缩放动画，但按压透明度、描边和记录状态仍可辨认。

## 2. 页面和练习

- [ ] 在首页、词库、刷题、错词、我的之间连续切换两轮，底部选中状态立即变化；无连续数秒空白或触摸无响应。
- [ ] 词库搜索内置词和个人词，打开10个不同词条；关联题数量出现及时，返回列表不重新卡住。
- [ ] 随机练习、分类练习、错词专项各进入一次；选项按下有视觉反馈，提交与下一题不重复记录。
- [ ] 在个人题目与内置题目混合的20题练习中连续作答，前后题响应没有明显越来越慢。
- [ ] 已有较多答题记录时打开“我的 → 答题记录”，滚动、切换“只看错题”和打开解析均无连续数秒停顿。
- [ ] 强制退出后重新打开 App，首页先可操作，提醒在后台稍后刷新，不因启动时重复登记通知而卡住。

## 3. 数据正确性

- [ ] 测试前记录一个词的错误次数、掌握程度、收藏和笔记；操作后核对本次反馈只增加一次，退出 App 再打开仍一致。
- [ ] 修改个人词或题后，搜索与关联立即更新；旧答题仍按旧版本显示和计分。
- [ ] 开启20:00提醒时连续学习，不出现一点击就连续弹权限或设置失败提示；退出重开后提醒开关保持。
- [ ] 导出备份并在另一台导入或附近同步，新增记录、个人词题和历史齐全，重复同步不重复计数。

## 4. iPad

- [ ] iPad Pro 2021 横屏双栏、竖屏和窄分屏分别切换词条、编辑个人内容和练习；旋转不丢草稿，按钮反馈可见。
- [ ] 横屏词库左侧快速切换20个词，右侧详情更新及时；长笔记、长解析能滚动，不拖慢整个 Tab 切换。

若仍出现“卡成 PPT”，记录发生前所在模块、已连续完成的大致数量、是否刚保存个人词/题，并录屏10秒；同时从“我的”导出当时备份。备份包含个人学习内容，不要上传到公开仓库，可单独发来用于复现。
