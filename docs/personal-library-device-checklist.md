# 手动词题功能：真机验收清单

本清单用于源码更新后的安装验收，不表示这些项目已通过。建议两台先从“我的”导出备份，保留旧版备份，再用同一个新版本 IPA 覆盖安装；不要先卸载。

## 1. 升级与独立保存

- [ ] 升级后核对一个已有词的错误次数、收藏、笔记及历史，和一条已有答题结果。
- [ ] 在词库新增“验收用词甲”，填写释义、分类“个人测试”、例句、辨析和笔记；保存后关闭并重新打开 App，核对全部字段。
- [ ] 搜索词形、释义片段；按“我的添加”和分类找到它；收藏、修改错误次数并进行词卡复习。
- [ ] 输入内置词的名称，确认不会覆盖内置资料，并能打开已有词。
- [ ] 空词/空释义/超长输入无法保存；取消未保存草稿先确认；保存失败保留输入。
- [ ] 自建词不会显示原始 PDF 页码。

## 2. 手动题目与历史

- [ ] 从内置词详情和自建词详情分别进入添加题目，当前词已关联。
- [ ] 输入题干、四个不同选项、解析；不选择答案时不能保存。空选项、重复选项和空关联词被拒绝。
- [ ] 在关联词选择中搜索、多选；创建另一个新词并返回，原题目草稿仍在。
- [ ] 录题中新增词时，填写一部分草稿后选择使用已有词：先确认放弃；选择继续编辑后草稿仍在。只打开已有词查看再返回，也不丢草稿。
- [ ] 录题过程中保存的新词独立保留；随后取消题目，不会把已保存的新词一起删除。
- [ ] 以“手动录入”题型开始练习。提交前只见题干/选项，不见答案、解析、关联词释义或笔记。
- [ ] 故意答错，核对关联词错误次数与题目历史。
- [ ] 修改此题正确答案、选项、解析和关联词；过去答题的结果、旧解析及原错词归属不变，新一组采用新版本。
- [ ] 改名自建词，已录入题目仍关联同一词条。
- [ ] 练习中通过另一台同步新修订，当前组题目不变化，也不会重复记分。

## 3. 归档与布局

- [ ] 归档词和题仍可在管理区找到、恢复，历史不会消失。
- [ ] 归档词不进入新词/错词/到期词日常练习和提醒；归档题不进入新练习组。
- [ ] iPad 横屏、竖屏和窄窗口来回切换，正在编辑的词/题和已选关联词不丢。
- [ ] 长中文能完整滚动查看，键盘不挡住保存，深浅色都清楚。
- [ ] 词条的个人笔记仍在释义下方，不回到底部。

## 4. 文件备份和附近同步

- [ ] 导出新版备份，另一台导入，新增词题和学习记录齐全；重复导入不重复计数。
- [ ] 导入旧 v2 备份，不清空已有自建内容。
- [ ] 两台分别添加不同词题，附近同步双方都能看到新增内容，即使尚无学习事件。
- [ ] 一台修改、另一台未修改，采用后继版本。
- [ ] 两台断开连接后独立编辑同一词/题，再同步时可查看两份完整内容并选择；重新同步不再弹出已处理冲突。
- [ ] 一台归档、另一台编辑，需确认，不自动恢复或覆盖。
- [ ] 两台独立建立同名词，选择一条保持活跃，另一条归档，双方原历史都保留。
- [ ] 本机出现内容冲突时，从“我的 → 处理本机内容冲突”完成选择，不需要另一台设备在线。
- [ ] 内容冲突处理后仍保留笔记/手动次数冲突选择；接收方能看到内容变化并确认。
- [ ] 个人资料较多时，确认冲突预览和逐项选择仍可正常响应；大资料的真机性能尚未测量。
- [ ] 预览后本机新增学习记录或编辑内容，旧方案被拒绝，要求重新预览。
- [ ] 确认前断线不保存；一方保存后断线，重新同步补齐，不重复计数。
- [ ] 新旧版连接提示升级两台，不交换不兼容快照。

## 5. GitHub 构建证据

- [ ] Python 回归测试和工程检查成功。
- [ ] 新增 Swift 行为测试在 macOS 实际编译并运行成功。
- [ ] iOS archive、Bundle 检查和 IPA 校验成功。
- [ ] Tag 对应 Release 提供带版本号的 IPA，安装后“我的”版本正确。
